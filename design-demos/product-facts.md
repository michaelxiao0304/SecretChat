# 首次对话的共同场景

依据本 worktree 的 README、ios/README.md、ios/App/SecretChatApp.swift、ios/App/DeviceModel.swift 和 ios/Shared/Profile.swift（提交 75e90fa）。三套原型都在浏览器内演示，使用合成数据。桌面展示板按 1440 × 900 px 比较；手机可直接操作。

- 邀请码、邮箱和邮箱验证码完成受邀注册。样例邮箱 demo@example.test，邀请码 M7KD-29QP，验证码 246810。普通流程假定安装包预设服务，开发入口保留可修改的 HTTPS 服务根地址和与测试服务配套的免验证码开关。生产客户端目前需要手动填写服务地址。
- 已注册用户签发一次性邀请并分享给对方。受邀人注册后，邀请双方成为联系人；首次启动目录未更新时可刷新。空列表也可能是首账号，生成自己的邀请仍有意义。客户端公开的联系人标识取短号 7a31c8d2，无经验证的姓名头像。
- 固定演示对话依次为我方“周六还是十点见吗？”，对方“十点，老地方见。”，我方“好，我会提前五分钟到。”。第一条可展示对方设备已收到；末条在已有会话下可在本机离线入队，再依演示事件显示服务端接收或对方设备确认。首次建会话需要先在线取得对方预密钥。
- 本地待提交、服务端接受、对方设备确认是三种证据。设备确认不提供阅读证据。目录中的设备 ID 或身份公钥与本地绑定不一致时暂停新发和重试。当前原型可以解释原因、返回或联系对方线下确认；当前客户端未提供安全码重新核验或一键恢复。
- 手机模拟器证据与 HTML 场景分开放。三个方向均可直接打开，无需真实服务、账户或验证码。
