## 采集方法

临时宿主直接编译提交 `75e90fa` 中的 [原始 SwiftUI 页面](../../ios/App/SecretChatApp.swift)、[DeviceModel](../../ios/App/DeviceModel.swift) 和 [Profile](../../ios/Shared/Profile.swift)。注册与空态通过原始 RootScreen 展示。会话由临时 NavigationStack 以联系人列表为上一级，打开原始 ConversationScreen。四个页面的视图代码均保持原样。

宿主向模型注入临时 Vault 和本地测试资料。两个临时身份通过项目内的 Signal 实现生成并解密测试消息，首条回执状态由夹具写入，最后一条留在本地发送队列。暂停场景替换对方公钥，原始 Profile.allows 判定为 false。整个采集在新建的专用模拟器上进行，无需连接注册、邮箱或推送服务。

在模拟器的 UIHostingController 挂载页面后，通过 UIWindow.drawHierarchy 与 UIGraphicsImageRenderer 按原始分辨率导出。四图保存后逐张核对了标题、正文和控件。截图覆盖预置状态的视觉表现，真实注册、邀请和跨设备投递流程另需联调验证。
